## About
This repository hosts my personal portfolio through GitHub Pages. It is being rebuilt as an interactive, motion-focused experience with a clean Apple-inspired visual system.

## Redesign direction
- Product-led stories instead of a generic gallery
- Live demos and source links
- Responsive desktop and mobile experiences
- Smooth motion with reduced-motion accessibility
- Expandable project case studies
- Space for future demo videos
- Education, certifications and hackathons
- Downloadable résumé and contact links
